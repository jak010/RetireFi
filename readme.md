# Investra (Toy Project)

Investra는 실시간 증권 데이터(네이버 금융, 토스증권, 야후 파이낸스, 로얄로더 등)를 융합하여 주도 섹터와 테마별 대장주를 분석하고, 실시간 장중 낙폭(눌림목) 감지 및 슬랙 알림을 제공하는 투자 보조 서버 어플리케이션입니다.

## 🚀 실행 가이드 (EXECUTE GUIDE)

- **COMMAND**
    ```shell
    # (옵션) 로컬 LLM 서버 실행
    $ OLLAMA_MLX=1 ollama serve
    
    # 서버 기동
    $ uvicorn src.main:app --reload
    ```

---

## 📋 기능 정의서 (Functional Specifications)

향후 요구사항 변경 및 확장의 기준이 되는 현재 구현된 시스템 기능 명세입니다. 기능 코드(ID)를 통해 요구사항을 쉽게 식별하고 관리할 수 있습니다.

| 기능 코드 | 카테고리 | 기능명 | 설명 (축약) |
| :--- | :--- | :--- | :--- |
| **MKT-01** | **마켓 테마 및 종목 요약** | 네이버 테마 분석 | 테마별 거래대금/등락률 기반 상위 주도 5대 테마 실시간 추출 |
| **MKT-02** | | 대장주 동적 판별 및 연동 | 복합 순위(대금+등락률) 기반 역할(대장주 등) 부여 및 로얄로더 시세 융합 |
| **MKT-03** | | 토스 랭킹 및 급등주 분석 | 토스증권 랭킹 및 당일 +24% 급등(상따) 후보 종목 테마 매핑 |
| **ALT-01** | **주도주 낙폭 감지/알림** | 장중 낙폭 실시간 모니터링 | 대장주 최고점 대비 1차 매수 밴드(-4.0% ~ -8.0%) 진입 감지 |
| **ALT-02** | | 스마트 필터링 알림 | 대금 1,500억 이상 & 테마 평균 등락률 양수(상승) 만족 시 알림 큐 추가 |
| **ALT-03** | | 슬랙(Slack) 통합 알림 | 알림 조건 만족 종목들을 배치로 묶어 쿨다운(1H) 적용 후 통합 발송 |
| **STA-01** | **실시간 시세/차트 통계** | 야후 차트/지수 연동 | 글로벌 지수 및 종목 5분봉 차트 연동을 통한 당일 장중 고점 산출 |
| **STA-02** | | 4개월 스윙/추세 통계 | 최근 60영업일 고/저점 대비 현재가 위치(머리/어깨/무릎 밴드) 분석 |
| **STA-03** | | 수급 및 이동평균선 분석 | 최근 20일 평균 거래량 대비 당일 수급 비율 및 10/20일 단기 이평선 판별 |
| **NWS-01** | **증권 뉴스 및 공시 연동** | 실시간 속보/공시 조회 | 종목코드 기반 네이버 증권 최근 속보(뉴스) 및 공시 실시간 스크래핑 |
| **NWS-02** | | 브리핑 리포트 다운로드 | 실시간 테마, 대장주, 낙폭 현황을 요약한 브리핑 텍스트(txt) 제공 |
| **NWS-03** | | LLM 뉴스 요약 (비활성) | Ollama 연동 최신 마켓 뉴스 요약 백그라운드 작업 |
| **SYS-01** | **캐싱 및 시스템 최적화**| 백그라운드 인메모리 캐싱 | Serverless 환경 딜레이 최소화를 위한 Stale-While-Revalidate 캐시 갱신 |
| **SYS-02** | | API 호출 청킹 최적화 | 외부 API Rate Limit 방지를 위한 30개 단위 병렬/분산 수집 |
| **UI-01**  | **관찰판 및 UI 최적화** | 대장주 기술적 분석 시각화 | 동적 구간 균등 분할(Piecewise) 방식 적용으로 가격 쏠림 현상 방지 및 시인성 극대화 |
| **UI-02**  | | 내 보유 종목 연동 및 필터링 | 토스증권 API 연동을 통한 내 보유 종목(자산) 하이라이팅(배지/색상) 및 관찰판 필터링 뷰 제공 |
