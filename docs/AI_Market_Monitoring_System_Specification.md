# AI 주도주 실시간 관제 시스템 상세 설계 및 제품 명세서

**System Specification & Technical Architecture Document (v4.5)**

본 문서는 실시간 국내 주식시장(KOSPI/KOSDAQ)의 수급 및 기술적 눌림목을 포착하는 'AI 주도주 실시간 관제 시스템'의 재현 가능하도록 작성된 상세 설계서입니다. 본 명세서에 기술된 아키텍처, 알고리즘, 연산 공식 및 데이터 구조를 그대로 준수하여 구현할
경우 시스템의 핵심 로직을 완전히 동일하게 재현할 수 있습니다.

---

## 1. 시스템 아키텍처 및 데이터 파이프라인

본 시스템은 데이터 연산의 정밀성과 실시간성을 동시에 확보하기 위해 **하이브리드 데이터 파이프라인(Hybrid Data Pipeline)** 구조를 채택합니다. 기술적 지표 연산을 위한 무거운 과거 데이터 레이어와 초단위 타점 포착을 위한 실시간 시세 레이어를
분리하여 상호 결합합니다.

### 1.1 데이터 소스 및 역할 분담

1. **`royalroader.load_realtime_theme_data()`**
    * **역할**: 장중 실시간 테마/섹터 구조 및 해당 섹터 내 소속 종목들의 실시간 기초 데이터(종목명, 소속 코드, 당일 등락률, 당일 거래대금, 기술적 대장주 여부)를 제공하는 핵심 마스터 데이터 소스입니다.
2. **`TossInvestmentAPI` (`toss_client`)**
    * **역할**: 국내 금융 인프라와 직결되어 지연 시간이 없는(Zero-Delay) 초단위 실시간 현재가(`lastPrice`)를 제공합니다. `yfinance` 등의 해외 파이프라인이 가진 15분 시세 지연을 원천 차단하고 실시간 낙폭 및 매수 타점 판정을
      수행하는 데 필수적인 요소입니다.
3. **`yfinance` (`yf`)**
    * **역할**: 과거 일봉 및 분봉 데이터를 수집하여 기술적 지표(이동평균선, 볼린저밴드, RSI, 거래량 비율)의 베이스라인을 연산합니다. 트래픽 최적화와 레이턴시 감소를 위해 메모리 내 세션 캐싱 구조를 적용합니다.

### 1.2 데이터 캐싱 정책

시스템의 무한 루프(`Streamlit rerun`) 구조 내에서 데이터 요청 과부하를 방지하기 위해 다음과 같은 캐싱 전략을 엄격히 적용합니다.

* **일봉 데이터 (`yf_cache`)**: 최근 6개월 일봉 데이터를 조회하여 세션에 보관하며, 타점 연산 시 당일 실시간 현재가를 마지막 일봉 종가에 오버레이(Overlay)하여 동적 지표를 재계산합니다. (TTL: 30분 장기 캐싱)
* **5분봉 데이터 (`yf_5m_cache`)**: 최근 5일간의 5분봉 데이터를 보관하여 5분봉 볼린저밴드 및 직전 5개 5분봉 평균 거래량(Vol_MA5)을 계산하는 데 활용합니다.
* **30분봉 데이터 (`yf_30m_cache`)**: 최근 1개월간의 30분봉 데이터를 보관하여 당일 30분 마디 고점을 계산하는 데 활용합니다.

## 2. 종목 선정 및 필터링 알고리즘 (Stock Selection Filter)

관제 대시보드 및 알림 엔진의 대상이 되는 종목 풀은 시장의 핵심 자금과 상승 강도가 집중되는 상위 섹터들로부터 동적으로 추출 및 결합됩니다.

### 2.1 섹터 스코어링 및 가중치 연산

각 섹터의 가중 평균 상승률($Rate_{sector}$)은 소속 종목들의 등락률 절대값을 가중치로 사용하여 연산됩니다. 이는 소수 대형주에 의한 왜곡을 방지하고 섹터 내 전반적인 상승 에너지를 정밀하게 반영합니다.

$$Rate_{sector} = rac{\sum_{i=1}^{n} (Rate_{stock, i} imes |Rate_{stock, i}|)}{\sum_{i=1}^{n} |Rate_{stock, i}|}$$

또한 섹터 내 소속 종목들의 당일 누적 거래대금($    ext{Volume}_{ ext{krw}}$)을 모두 합산하여 섹터별 총 거래대금($Vol_{sector}$)을 연산합니다.

### 2.2 상위 섹터 결합 및 중복 제거 범위

1. **상승률 기준**: 연산된 가중 평균 상승률($Rate_{sector}$)이 높은 최상위 3개 섹터를 추출합니다.
2. **거래대금 기준**: 섹터별 총 거래대금($Vol_{sector}$)이 많은 최상위 3개 섹터를 추출합니다.
3. **통합 풀(Pool) 생성**: 두 기준에서 추출된 섹터 리스트를 병합한 뒤 중복을 제거(Union)하여 최종 **관제 대상 핵심 섹터 풀**을 확정합니다.

### 2.3 섹터 내 종목별 역할 할당 규칙 (Role Assignment)

선정된 핵심 섹터 내 소속된 모든 종목은 실시간 스크리닝을 통해 다음 4가지 역할 중 하나로 바인딩됩니다.

* **Leader (대장주)**: 테마 데이터 원본 상 기술적 대장주(`leader_stock`) 명칭과 일치하는 종목.
* **1st (1등주)**: 당일 해당 섹터 내에서 실시간 상승률이 가장 높은 종목.
* **2nd (2등주)**: 당일 해당 섹터 내에서 실시간 상승률이 두 번째로 높은 종목.
* **Main (주도주)**: 당일 해당 섹터 내에서 실시간 누적 거래대금 기준 최상위 3개 범위에 포함되는 종목.
* **Etc (기타 종목)**: 위 4가지 조건에 해당하지 않는 하위 종목.

### 2.4 거래대금 하한 필터링 (Liquidity Threshold)

* **핵심 등급 보호**: `대장주`, `1등주`, `2등주`로 분류된 핵심 종목은 당일 거래대금 규모와 관계없이 조건 검증을 위해 **무조건 관제 풀에 유지**합니다.
* **주도주 및 기타 종목 필터**: `주도주` 또는 `기타` 종목의 경우, 당일 누적 거래대금이 **30억 원 미만**일 경우 수급 부재로 판단하여 관제 화면 및 알림 대상에서 즉시 제외(Drop)합니다.

## 3. 기술적 지표 및 수급 상태 연산 공식

각 종목의 UI 그리드에 표출될 계량 데이터 및 상태값의 정확한 연산 로직은 다음과 같습니다.

### 3.1 이동평균선 정렬 상태 (Moving Average Status)

최근 일봉 데이터를 기반으로 당일 실시간 현재가를 종가에 실시간 반영한 뒤 5일, 20일, 60일 이동평균선($MA_5, MA_{20}, MA_{60}$)을 구하여 정렬 상태를 스트링으로 반환합니다.

* **정배열**: $MA_5 > MA_{20} > MA_{60}$
* **역배열**: $MA_5 < MA_{20} < MA_{60}$
* **혼조**: 위 두 조건에 해당하지 않는 모든 상태

### 3.2 수급 상태 (Liquidity Status)

당일 누적 거래대금의 규모(원화 기준)와 최근 5거래일 평균 거래량 대비 당일 거래량 비율($Ratio_{vol, 5d}$)을 결합하여 가전환 매트릭스 등급을 부여합니다.

$$Ratio_{vol, 5d} = rac{ ext{당일 실시간 누적 거래량}}{ ext{최근 5거래일 평균 거래량}} imes 100$$

* **A+ (지속 유입)**: 당일 누적 거래대금 $\ge$ 500억 원 이면서 $Ratio_{vol, 5d} \ge 150\%$ 인 경우
* **A (대금 충분)**: 당일 누적 거래대금 $\ge$ 300억 원 인 경우 (A+ 조건 미충족 시)
* **B+ (거래 가속)**: $Ratio_{vol, 5d} \ge 120\%$ 인 경우 (위 조건 미충족 시)
* **C (수급 부족)**: 위 세 가지 조건에 모두 미달하는 경우 (UI상 흐리게 표시하여 리스크 경고)

### 3.3 5분봉 거래량 상태 (5-Minute Volume Analysis)

최근 완료된 5분봉 캔들의 종가($Close_{5m}$), 시가($Open_{5m}$), 거래량($Vol_{5m}$) 및 5분봉 기준 5평균 거래량($VolMA_{5, 5m}$)의 유기적 관계를 분석하여 현재 주가의 숨고르기(눌림) 상태의 건전성을 평가합니다.

* **`감소(눌림 양호)`**: $Close_{5m} < Open_{5m}$ (음봉) 이면서 $Vol_{5m} < VolMA_{5, 5m}$ 인 경우 -> 주가가 하락하고 있으나 매도 거래량이 평균 이하로 급감하여 건전한 조정으로 판정합니다.
* **`증가(수급 유입)`**: $Close_{5m} \ge Open_{5m}$ (양봉) 이면서 $Vol_{5m} > VolMA_{5, 5m}$ 인 경우 -> 거래량이 수반된 강한 매수세 유입으로 판정합니다.
* **`안정`**: 위 두 가지 특이 조건에 해당하지 않고 거래량이 균형을 이루는 상태.

## 4. 실시간 알림 엔진 및 매수 타점 스캐너 (Alert Engine)

시스템은 수집된 실시간 가격 정보를 기반으로 상시 모니터링을 수행하며, 다음 조건이 충족되는 순간 Slack 채널을 통해 알림을 발생시키고 관제 세션 상태를 변경합니다. 변동성 낙폭률 연산의 절대적 기준점은 당일 장중 도달한 최고가인 **장중
고점($High_{day}$)**입니다.

### 4.1 1차 매수구간 진입 (1st Entry Zone)

* **판정 조건**: 장중 고점 대비 당일 실시간 낙폭률($Drop_{day}$)이 3% 이상, 4% 이하 범위에 진입했을 때 발생합니다.
  $$Drop_{day} = rac{High_{day} - Current_{price}}{High_{day}} imes 100 \quad \Longrightarrow \quad 3.0\% \le Drop_{day} \le 4.0\%$$
* **알림 프로토콜**: `[1차 매수구간 진입] 종목명 (코드)` 형태로 Slack 알림이 즉시 발송됩니다. 과도한 중복 알림을 차단하기 위해 해당 종목에 대해 **1시간(3,600초)의 쿨다운(Cooldown)** 타임아웃이 적용됩니다.

### 4.2 2차 매수구간 진입 (2nd Entry Zone - F-Zone 수급 포착)

* **판정 조건**: 장중 고점 대비 당일 실시간 낙폭률($Drop_{day}$)이 4% 초과, 8% 이하 범위에 진입했을 때 발생합니다.
  $$4.0\% < Drop_{day} \le 8.0\%$$
* **알림 및 시스템 액션**:
    1. `[2차 매수구간 진입] 종목명 (코드)` 형태로 Slack 위험 알림이 발송됩니다. (1시간 쿨다운 적용)
    2. 해당 종목의 메타데이터(포착 시각, 포착 가격, 진입 시점의 고점 정보 등)가 세션 상태의 `f_zone_tracked_stocks` 저장소에 즉시 등록됩니다.
    3. 등록된 종목은 장중 실시간 스크리닝 대상 섹터에서 이탈하더라도 **당일 장 마감 시까지 UI 그리드에서 상시 누적 추적**되며, 마스터 그리드 상에서 **붉은색 배경 테두리로 하이라이트** 처리되어 강조됩니다.

### 4.3 볼린저밴드 하단 터치 (Bollinger Band Lower Touch - 관찰 종목)

* **판정 조건**: 5분봉 데이터 레이어에서 계산된 실시간 20선 기준 볼린저밴드 하단선($LowerBand_{20, 2}$) 수치와 현재 5분봉의 저가($Low_{5m}$)를 실시간 비교합니다.
  $$Low_{5m} \le LowerBand_{20, 2} \quad 	ext{where} \quad LowerBand = MA_{20} - 2 	imes \sigma_{20}$$
* **알림 프로토콜**: 단기 과매도 구간의 최하단에 도달했음을 의미하므로 `[BB 하단 터치 - 관찰 종목] 종목명 (코드)` 알림이 즉시 발송되며, 기술적 반등 유무를 관찰하도록 유도합니다. 해당 알림은 **30분(1,800초)의 단기 쿨다운**이 적용됩니다.

## 5. UI 마스터 그리드 컬럼 및 표출 데이터 명세

UI 화면 상의 데이터 그리드는 명세서에 정의된 컬럼 표준 규격에 맞추어 정확하게 매핑되며, 데이터 미존재 시 대시 기호(`-`)로 예외 처리됩니다.

| 컬럼명         | 정량적 데이터 소스 및 연산 로직                                 | 화면 표출 규칙 및 예시                            |
|:------------|:---------------------------------------------------|:-----------------------------------------|
| **포착 분류**   | 당일 $Drop_{day}$ 기반 알림 엔진 상태 바인딩                    | `1차눌림` / `주도주` (F-존) / `⏳ 관망추적`          |
| **종목명**     | 한국거래소(KRW) 상장 표준 단축 이름                             | `삼성전자`, `에코프로비엠`, `현대차`                  |
| **역할**      | 섹터 내 주도력 조건 판정 결과 영문 매핑                            | `Leader` (대장), `1st`, `2nd`, `Main` (주도) |
| **등락률**     | 전일 종가 대비 현재가 등락 백분율                                | `+4.12%`, `-1.25%` (부호 명시, 소수점 2자리)      |
| **거래대금**    | 당일 장중 누적 거래대금 원화 환산                                | `5,230억원`, `852억원` (천 단위 콤마 필수)          |
| **거래량**     | 일봉 기반 최근 5거래일 평균 대비 배수                             | `평균 대비 2.8배` (소수점 1자리 제한)                |
| **수급 상태**   | 대금 규모 및 가속도에 따른 결합 등급                              | `A+ (지속 유입)`, `A (대금 충분)`, `C (수급 부족)`   |
| **현재가**     | `toss_client` 수신 초단위 실시간 체결가                       | `82,500원` (천 단위 콤마 포함 원화 표기)             |
| **장중 고점**   | 당일 분봉 및 일봉 데이터 중 기록된 최고가                           | `84,000원`                                |
| **장중 낙폭**   | $High_{day}$ 대비 현재가의 하락률 ($Drop_{day}$)            | `-1.79%`, `-5.42%` (마이너스 부호 필수 명시)       |
| **30분 낙폭**  | 최근 30분 마디 고점 대비 실시간 하락률                            | `-0.92%` (단기 분봉 변동 속도 인덱스)               |

## 6. 예외 처리 및 가시성 가이드라인 (Error & UI Handling)

동일한 시각적 효과와 안정성을 확보하기 위해 다음 3가지 예외 규칙을 프론트엔드/백엔드에 공통 적용합니다.

1. **수급 부재 종목 비활성화**: 수급 상태 컬럼의 값이 `C (수급 부족)`인 행(Row)은 화면 상에서 불투명도 60% 처리 및 연한 회색(`#9ca3af`) 폰트로 렌더링하여 투자자의 진입 대상에서 시각적으로 분리합니다.
2. **F-Zone 최상위 대장주 강조**: `f_zone_tracked_stocks`에 진입한 종목들 중, 역할이 `Leader` 혹은 `1st`인 핵심 주도주가 2차 매수구간에 머무르고 있는 경우 해당 행의 배경색을 **붉은색 계열(알파값 85% 투명도 포함)**
   로 채우고 글씨를 굵게(`font-weight: 700`) 처리하여 실시간 시각 관제 가시성을 극대화합니다.
3. **네트워크 단절 대응**: 토스 API 등 외부 시세 소스로부터 네트워크 에러가 발생하여 실시간 시세 수신이 일시 실패할 경우, 시스템은 강제 다운되지 않고 즉시 직전 메모리에 보관된 `yfinance` 기반 캐시 시세를 오버레이 대체재로 활용하여 파이프라인의
   영속성을 유지합니다.
