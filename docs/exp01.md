# 종목 선정

화면에 표출될 종목은 다음 두 가지 항목이다.

1. 거래대금이 많은 섹터의 대장주,주도주,1등주,2등주
2. 상슬률이 높은 섹터의 대장주,주도주,1등주,2등주

# 알림

선정된 종목 중 다음 조건이 발생하면 Slack 알림을 발생한다.

1. 1차 매수구간 : 장중 고점 3% ~ 4% 하락 시
2. 2차 매수구간 : 장중 고점에서 4% ~ 8% 하락 시
3. 현재 가격이 볼린저밴드 하단에 터치 한 경우 (관찰 종목)

# 종목 칼럼

각 종목을 UI로 구성할 떄 다음 컬럼을 통해 표시한다.

| 컬럼명     | 예시               |
|---------|------------------|
| 포착 분류   | 주도주              |
| 종목명     | 삼성전자             |
| 역할      | Leader           |
| 등락률     | +4.12%           |
| 거래대금    | 5,230억원 (시장 3위)  |
| 거래량     | 평균 대비 2.8배       |
| 수급 상태   | A+ (지속 유입)       |
| 현재가     | 82,500원          |
| 장중 고점   | 84,000원          |
| 장중 낙폭   | -1.79%           |
| 30분 낙폭  | -0.92%           |
| 이평선 정렬  | 정배열              |
| 5분봉 거래량 | 감소(눌림 양호)        |
| 1차 매수구간 | 80,640 ~ 78,960원 |
| 2차 매수구간 | 77,414 ~ 74,222원 |
